# flomo 导出适配

flomo 官方支持全局导出及按标签/搜索条件导出，内容格式为 HTML。官方入口说明：
https://help.flomoapp.com/basic/storage.html

让用户使用其已导出的 HTML、ZIP 或导出目录；不要求 flomo API token，不登录或调用在线服务。其他导出样式先检查，不从产品名称推断文件结构。

当前转换器适配明确的 class 边界：每条 `.memo` 内恰好一个 `.content`，可选 `.time`。这些选择器是可配置适配规则，不是官方稳定契约。先检查实际文件；需要时用 `--memo-class`、`--content-class`、`--time-class` 指定实际 class。每个 HTML 找不到笔记或正文不唯一时会报错，避免静默漏导。导出目录包含非笔记 HTML 时，应选择已核实的笔记文件单独转换，之后合并候选。

转换保留段落、换行、正文中的标签文本、可见链接及其地址；不会自动将正文里的 `#文字` 提取为结构化 `tags`。需要结构化标签时，按用户指定范围整理候选 JSON，并保留原文。来源使用 `flomo` 和能明确识别的导出时间；不从正文猜作者/日期。图片、音视频不进入 text，报告每条遗漏数量和纯媒体空条目；不做 OCR，不读取媒体本身，不执行 script/style。列表编号、表格排版、富文本样式不保证复原，先对照代表样本。

不保证兼容所有导出版本。遇到其他结构，可按原笔记边界生成统一候选 JSON，仍复用同一个 plan/apply 流程，不绕过预览、去重和冲突检查。
