# 使用与排查

从具体症状检查，不重装或清空数据作为默认修复方式。

| 症状 | 检查顺序 |
| --- | --- |
| 首次打开被系统拦截 | 核对下载来源与具体提示；未公证版本按 README 单独允许，损坏或恶意软件提示另查原因 |
| 看不到应用主窗口 | App 常驻菜单栏，没有 Dock 主窗口；先确认进程和菜单栏入口 |
| 笔记已导入但数量不变 | 核对目标路径与回执；使用已验证 App 的重载接口，不重新反复写入 |
| 没有自动展示 | 暂停状态、自动展开、计划频率、空内容池、显示屏幕；手动“立即回顾”可单独测试展示 |
| 悬停不展开 | 悬停开关、暂停、热区；手动收起后先离开再进入 |
| 手动按钮不可用 | 暂停或空池；编辑器内还需先保存草稿 |
| 标签筛选后找不到笔记 | 清空搜索并切回“全部”；“默认”只包含无标签内容，筛选没有删除笔记 |
| 改了标签但回顾仍出现其他内容 | 标签只筛选编辑列表，回顾仍从全部内容选择；不要通过删除其他内容改变范围 |
| 标签或删除操作未生效 | 检查是否完成“保存并生效”；切换条目不会自动保存 |
| 保存出现冲突 | 保留草稿，核对导入或外部编辑产生的新内容；不要强制覆盖 |
| 撤销导入 | 当前文件有效时，选择明确备份并生成 replace 恢复预览，按授权执行 |
| 文件损坏 | 保留原始文件，核实备份并交付修复候选；脚本会拒绝解析失败的目标，不能直接用 replace 覆盖损坏文件 |
| 与其他刘海工具重叠 | 提供“让出刘海区域”或切换屏幕选项，不自动关闭其他软件 |

重载只读取 App 自身的数据路径，不主动展示；`reloaded` 不是用户已读的证据。睡眠/锁屏恢复不补播错过内容，暂停时手动展示也关闭。界面无法访问时不要猜测用户当前设置。

记录版本、症状、检查结果及下一步即可，诊断输出不包含笔记正文。需要回顾频率等偏好变更时遵循用户明确意图，不能为了让测试通过而静默解除暂停。
